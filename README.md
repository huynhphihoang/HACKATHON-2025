# HACKATHON-2025 (DoomCode)
*GitHub Repository for HACKATHON-2025, organized by the CS Club and UPC.*

## Overview
This is an web-application that helps programmers of all levels learn and study concepts in the form of short videos.
The alignment with the theme: Merging Doomscrolling with Productivity and Education

## Content Management System
We decided to utilize Strapi, an open-source headless CMS for its robust and dynamic back-end handling. The team focused on the UX flow and back-end data retrieval design, without too much focus on technical set up for back-end architectures
